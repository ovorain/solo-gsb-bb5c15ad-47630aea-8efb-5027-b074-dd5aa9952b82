# 条款引用校验台

本地运行的中文法规条款编号与交叉引用校验工具。粘贴含「第 X 条 / 款 / 项」编号与交叉引用的条款文本，系统自动解析为可折叠的 **条 → 款 → 项** 层级文档，在正文与关系视图之间联动高亮引用，实时检测断链、自引用与循环引用，并在拖拽调整条款顺序后**原子更新**所有可唯一定位的引用；还可把任意时刻的文档保存为**命名快照**，在「版本对比」视图按稳定节点 ID 比较两个版本的节点增删改、移动与引用差异；「问题与引用」面板还能把检测结果保存为**命名问题基线**，按稳定问题身份（类型 + 源节点 ID + 引用原文 + 同文序次，循环为排序节点 ID 集合）把实时问题分为新增、已解决、仍存在三类比较。右侧「审阅批注」面板支持对条 / 款 / 项正文的任意片段创建批注，批注以**稳定节点 ID + 引用片段 + 前后文锚点**持久化，正文或结构调整后自动尝试重定位，片段缺失或多处匹配时标记待复核并保留候选位置。右侧第 4 个标签「**规范用语审校**」允许维护「规范词 + 多个禁用变体」规则，实时列出命中所在条款与上下文，点击结果定位正文，勾选后批量替换为规范词（提交前逐项核对节点 ID 与原文区间，整批原子替换、可整体撤销 / 重做）。「关系视图」标签内还提供「**引用影响分析**」：选中任一条款后，基于当前确认后的解析图按距离分层列出所有直接 / 间接引用它的源条款并统计各层数量，循环路径自动去重并标注，结果行可点击跳回正文；分析仅用于当前会话，不修改正文、不写入撤销历史。右侧第 5 个标签「**修订沙盒**」为条级删除 / 移位 / 换号提供**预演**：在文档克隆上复用结构改写与问题分析逻辑，按来源节点列出将被改写的引用与将新增 / 消失的断链、循环问题，结果可点击定位当前正文；预演记录生成时的正文版本，正文变化后失效并禁止应用，未失效时可一步应用并整体撤销 / 重做。右侧第 6 个标签「**引用阅读**」可在选定一条后生成**引用阅读包**：沿当前已确认的引用关系向目标方向逐层收集直接及间接依赖的条款（组合引用的每个已解析目标都参与收集），循环与多路径汇合只收录一次，按原文档顺序完整展示条、款、项原文（保留原编号与正文，不改写），并把收录条款中的断链 / 歧义引用单列为警示（标明来源、原文与原因），支持一键复制纯文本与从条目跳回正文；正文或歧义确认变化后阅读包自动过期，必须重新生成，不能复制旧结果。

- 纯本地运行，数据保存在浏览器 `localStorage` 与本机文件，无需任何外部账号或网络服务。
- 技术栈：React 18 + TypeScript（Vite）+ Node.js / Express。

## 一条命令启动（推荐 Docker）

需要 Docker 与 Docker Compose（v2）。

```bash
docker compose up --build
```

启动后浏览器访问：

> **http://localhost:3000**

数据持久化在命名卷 `clause-data`（容器内 `/data/state.json`）。停止与清理：

```bash
docker compose down            # 停止（保留数据）
docker compose down -v         # 停止并删除数据卷
```

若要改用目录挂载而非命名卷，可在 `docker-compose.yml` 中把 `clause-data:/data` 改为 `./data:/data`。

## 不用 Docker，直接用 Node 运行

要求 Node.js 20+。

```bash
npm install
npm run build
npm start
```

同样访问 http://localhost:3000 。

开发模式（前端热更新 + 后端自动重启，前端在 5173，API 代理到 3000）：

```bash
npm run dev
```

健康检查：`curl http://localhost:3000/api/health`

## 功能说明

### 1. 粘贴解析
- 点击右上角「粘贴 / 导入」，把条款文本贴入即可。
- 识别规则：
  - `第一条`、`第 12 条`、`第十条之一` 开头的行作为**条**，行内 `【标题】` 作为条标题；
  - 条下的自然段落为**款**；`（一）`、`(一)`、`【一】`、`一、`、`1.` 等形式识别为**项**；
  - 数字支持中文（一、十、二十三、一百零五）、阿拉伯与全角数字；
  - 编号保留原文（支持跳号与「之一/之二」后缀条），款、项按结构位置编号。
- 也可在弹窗中选择之前导出的 JSON 文件恢复数据，或载入内置示例。

### 2. 可折叠层级与正文编辑
- 条可折叠；点击条号（如「第五条」）可直接输入新编号，与目标位置的条交换顺序。
- 点击任意正文即可就地编辑，`Ctrl+Enter` 保存、`Esc` 取消；编辑过程中的连续输入在撤销时合并为一次。
- 条标题栏左侧的 ⠿ 手柄可**拖拽排序**；支持 `+款 / +项 / +条` 新增与删除。

### 3. 引用解析与联动高亮
正文内可识别的引用形式包括：

| 类型 | 示例 |
| --- | --- |
| 条级组合引用 | `第三条、第五条及第七条`、`第三条和第五条`（暂不解析组合中的款、项） |
| 条级闭区间 | `第三条至第五条` |
| 绝对引用 | `第五条`、`第十二条之一`、`第五条第二款`、`第五条第二款第（一）项` |
| 本条 | `本条第三款`、`本条第二款第（二）项` |
| 相邻条 | `前条`、`上条`、`后条`、`下条` |
| 款 / 项相对引用 | `前款第（二）项`、`前项`、`本款第（一）项`、`本项`、`（三）` |

- 组合引用与闭区间解析为**按文档顺序排列的稳定条 ID 集合**：正文高亮与关系视图会把该表达同时关联到全部目标（悬停时所有目标条款一并发光，关系图中每个目标各有一条边）。
- 组合 / 区间中任一目标不存在、或区间端点因同序号后缀条（如「第八条之一」）而有歧义时，整段标记为问题，**问题面板会分别列出已解析目标（可点击定位）与缺失目标（含原因）**。
- 有效引用为绿色，断链红色波浪下划线，自引用黄色，歧义引用蓝色。
- **悬停**正文里的引用：引用本身高亮，目标条款卡片发光。
- **点击**有效引用：滚动并定位到目标节点（组合引用定位到第一个目标）。
- 右侧「关系视图」以环形图展示条级引用边：悬停/点击边与正文双向联动，自引用为黄色自环、处于循环中的边与节点标紫、含断链的条标红。

### 4. 结构调整后的原子改写
- 拖拽排序、点击条号改编号、新增/删除节点后，系统对照调整前的解析结果：
  - 对所有**可唯一定位**的绝对引用一次性、按字符偏移原子改写（如第三条移到末尾，「第三条」自动变为「第五条」），保留原文数字风格（中文/阿拉伯）与「（X）」括号写法及条名；
  - **组合引用 / 闭区间保持原目标集合**：调整后目标仍连续时输出闭区间（如「第二条至第四条」），不连续时展开为顿号列表（如「第二条、第四条、第六条」），并沿用原数字风格；
  - 组合 / 区间的**任一目标被删除或端点有歧义时整段不改写**，并在问题面板列出已解析与缺失目标；
  - 相对引用（本条、前款、前项、后条……）**不改写**，由结构位置自动跟随；
  - 操作结束后弹出提示，告知自动改写数量与未处理数量。
- 整个结构操作与改写（含组合引用的改写）是一次提交，可整体「撤销 / 重做」（按钮或 `Ctrl+Z` / `Ctrl+Y`，`Ctrl+Shift+Z`）。

### 5. 不可唯一定位的引用：只列候选，绝不自动改写
以下情况标记为**歧义**，不会被自动改写，而是在右侧问题面板列出全部候选，由用户单选确认：

- 存在同序号条（如同时有「第八条」与「第八条之一」时，单独写「第八条」）；
- 只给项号、未给款号，且同一条多款下都有该序号项。

确认后该引用按所选目标解析并参与后续结构改写；确认记录会保留在问题列表中（标记「已确认」），可随时跳转目标或撤销确认。

### 6. 问题检测与跳转
右侧「问题与引用」实时统计并分类：

- **断链**：目标条/款/项不存在，或相对引用越过边界（如第一条引用「前款」）；
- **自引用**：引用解析到其所在节点自身（如项内写「本项」自指）；
- **循环引用**：条级有向图上的环（如第六条 ↔ 第七条互相援引），列出完整环路；
- **歧义引用**：见上节。

点击问题中的源句可跳到正文对应句子并高亮；点击目标/环路节点可跳到对应条款。

### 7. 问题基线（新增 / 已解决 / 仍存在）
「问题与引用」面板顶部的「**📌 问题基线**」可把**当前检测结果**保存为命名基线，随后把实时结果与任一基线比较：

- 在基线栏输入名称（如「一审基线」）点「**保存为基线**」即自动进入比较；也可随时点击已有基线切换比较、再次点击退出；
- 问题以**稳定身份**对齐：
  - 普通问题 = **问题类型 + 源节点稳定 ID + 引用原文 + 该节点内的同文序次**（同一节点内同原文第几次出现）；
  - 循环引用 = **问题类型 + 排序后的稳定节点 ID 集合**（环路的方向 / 起点变化不另算新问题）；
  - 身份**不含字符偏移**：在引用前后增删文字导致偏移变化时，问题仍判为同一个，不会制造“新增 + 已解决”的假象；
- 比较结果分为三类，可分别筛选：
  - **新增**（绿色）：基线中没有、实时结果中新出现的问题；
  - **已解决**（红色）：基线中有、实时结果中已消失的问题；
  - **仍存在**（黄色）：两侧都有，显示「基线定位 → 当前定位」（条款移动时两处定位不同）；
- **点击任意比较行可跳到现存源句**：新增 / 仍存在跳当前位置；已解决问题按源节点与引用原文在当前文档中重新定位源句（仅引用前文字变化时自动跟随新偏移）；源节点已删除的已解决问题标注「源节点已删除，不可跳转」；
- 基线是保存时刻文档与歧义确认记录的**只读深拷贝**，不随后续编辑变化；**删除基线不影响正文**、确认记录、批注、规则与撤销历史；
- 基线随 `localStorage`、后端文件与 JSON 一并持久化 / 导入导出；比较时一律按基线文档重新分析重建问题身份，旧数据缺少 `issueBaselines` 字段时按**空列表**加载。

### 8. 撤销 / 重做 与 JSON 导入导出
- 顶部「↶ 撤销 / ↷ 重做」，历史最多保留 100 步；连续文本输入自动合并。批注的创建、编辑、删除、候选确认与规范用语规则的增删改、批量替换同样进入撤销历史。问题基线与版本快照为独立的只读留痕，**不进入撤销历史**。

### 9. 审阅批注

右侧第 3 个标签「**审阅批注**」提供条 / 款 / 项正文片段的批注能力：

- **创建**：在正文非编辑态下用鼠标选取任意片段，松开鼠标后选区上方弹出批注框；输入内容后 `Ctrl+Enter` 或点「添加批注」即可。被批注的片段以下划波浪线标记（浅蓝为已定位、黄色为待复核），片段横跨引用 chip 时 chip 会加虚线描边。
- **编辑 / 删除**：在侧栏批注行点「编辑」改批注正文，「删除」移除（均可随正文撤销 / 重做恢复）。
- **筛选与跳转**：侧栏可按「全部 / ✓ 已定位 / ⚠ 待复核」筛选；点批注行或正文中的批注标记会**滚动定位并高亮**对应片段（所属条折叠时自动展开），同时侧栏同步选中该批注。
- **持久化锚点**：每条批注保存稳定节点 ID、引用片段原文（`quote`）以及前后各 24 字的前后文锚点（`prefix` / `suffix`）。
- **自动重定位**：每次正文编辑或结构调整（拖拽、新增、删除等）后自动尝试重新定位，按顺序使用：
  1. 原节点内精确匹配且**唯一** → 更新偏移，保持锚定；
  2. 原节点内忽略空白 / 标点差异的归一化唯一匹配 → 重新锚定（区间扩展覆盖插入的标点）；
  3. 全文其他节点归一化唯一匹配（如片段随条款移动）→ 锚定到新节点；
  4. 片段出现多处（原节点多处为 `multi-in-node`、全文多处为 `multi-match`）或彻底缺失（节点仍在为 `missing`、节点已删为 `node-missing`）→ 标为**待复核**，并保留按前后文相似度评分排序的候选位置。
- **候选确认**：待复核批注在侧栏列出全部候选（含节点定位与上下文预览），可先点击跳转核对，再点「确认」把批注重新锚定到所选位置；确认后的批注在后续编辑中仍继续参与自动重定位。
- 结构操作后若新增待复核批注，顶部通知条会一并提示数量。

### 10. 版本对比（命名快照）

入口：顶部工具栏的「**版本对比**」标签（「正文编辑」标签可随时切回）。

- 在版本对比页顶部输入名称（如「一审稿」），点击「**📸 保存当前为快照**」，即可把**当前文档**冻结为只读命名快照。继续编辑后再保存一个版本，就能选择任意两个快照进行比较。
- 节点以**稳定节点 ID** 对齐条、款、项，分别标出：
  - **新增**（绿色）、**删除**（红色）、**正文修改**（黄色，行内以逐字增删高亮）、**位置移动**（紫色，显示「旧位置 → 新位置」）；
  - 同一节点同时发生移动与正文修改时，**两类标记同时保留**。
- 「引用」标签页按**源节点 ID + 引用原文 + 同文序次**（同一节点内同原文第几次出现）对齐引用，列出：
  - **新增引用**、**移除引用**、**目标变化**（原文不变但解析到的目标节点不同，含旧目标 → 新目标）；
  - 每条差异都可点「**→ 跳到当前版本**」回到正文对应节点（该节点已在当前版本删除时不显示跳转）。
- 可勾选「仅显示有变化的节点」折叠未变化部分。
- 快照**只读**：保存后不再随后续编辑变化；删除快照**不影响正文、确认记录、批注、规范用语规则与撤销历史**。快照随 JSON 一并导出/导入（含保存时刻的批注与规范用语规则）；旧版导出文件缺少 `snapshots` 字段时按空列表加载。

### 11. 规范用语审校

右侧第 4 个标签「**规范用语审校**」用于维护「规范词 + 多个禁用变体」词表并批量统一用语。

- **维护规则**：点「**+ 新增规则**」增加一条，填一个**规范词**（替换目标）和若干**禁用变体**（用顿号 / 逗号分隔，回车或失焦保存）；可随时编辑、删除，并用 ↑ / ↓ 调整规则顺序。与规范词相同的变体自动剔除。
- **实时命中**：规则或正文每次变化都即时扫描，按条款顺序列出每条命中的**所在条 / 款 / 项定位**与上下文（命中变体高亮），正文内的命中处以黄色波浪下划线标出。
- **重叠消解**：同一位置被多个变体 / 规则命中时，按 **① 起点靠前 → ② 变体较长 → ③ 规则顺序靠前** 的优先级消解，最终命中两两互不交叠。
- **点击定位**：点击侧栏命中行（或正文里的命中标记）会滚动定位到正文对应片段并高亮，所属条折叠时自动展开，正文与侧栏双向联动。
- **勾选批量替换**：逐条勾选或用「全选」，点「**批量替换为规范词**」统一替换：
  - 替换**只处理扫描快照中的已选命中**；提交前逐项核对**节点 ID 与原文区间**（含该节点扫描时的完整正文），**任一项已变化（正文被编辑、节点被删除或结构调整）则整批拒绝**，不会改动任何文字，界面提示重新勾选；
  - 全部有效时**按节点从后向前、单遍替换**，因此替换新生成的文字**不会被递归处理**；
  - 整批替换作为**一步**进入历史，可用顶部「↶ 撤销 / ↷ 重做」（或 `Ctrl+Z` / `Ctrl+Y`）整体恢复；规则的增删改同样可撤销（连续输入合并为一步）。
- 规则与正文一同保存在 `localStorage` 与后端文件，并随 JSON 导出 / 导入；旧数据缺少 `termRules` 字段时按**空规则**加载。

### 12. 引用影响分析（关系视图）

「关系视图」标签下方的「**引用影响分析**」模块用于评估修改 / 删除某一条款的影响面：

- **选择目标**：点击关系图中的任意节点，或在模块下拉框中选择条款，即以其为目标开始分析；被选中的节点在图中以蓝色光环标出；
- **分层结果**：基于**当前确认后的解析图**（含已确认的歧义引用）沿「谁引用了它」反向遍历，找出所有直接及间接引用该条款的源条款，按最短引用距离分层展示（第 1 层为直接引用，其余为间接引用），并统计各层与总数量；
- **跳回正文**：点击任一结果行即滚动定位到正文对应条款，悬停结果行也会在正文中联动高亮；
- **循环去重与标注**：同一条款被多条路径引用时只按最短距离列出一次；处于引用循环上的条款以「↻ 循环」徽标标注，目标自身处于循环中时也会给出提示，页脚同时报告已去重的重复 / 循环路径条数；
- **刷新与清空**：正文编辑后结果会提示「已过期」，点「**刷新**」按最新解析图重新计算，「**清空选择**」清除目标与结果；
- **会话内临时分析**：结果不持久化、不修改正文、不写入撤销历史，仅用于当前会话评估影响范围。

### 13. 修订沙盒（条级删除 / 移位 / 换号预演）

入口：右侧第 5 个标签「**修订沙盒**」（应用访问地址见上文，Docker 一键启动后为 **http://localhost:3000**）。

- **预演入口**：选择条款与操作——**删除该条**、**移位**（移动到第 N 位）、**换号**（改为第 N 条，与点击条号改编号同一语义）——点「**开始预演**」；
- **克隆上预演**：预演在当前文档的**克隆**上复用与正文编辑完全相同的结构改写（`applyStructuralChange`）与问题分析（`analyze`）逻辑，**不改动正文、确认记录与撤销历史**；
- **结果按来源节点列出**：
  - **将被改写的引用**：按来源节点分组，逐处显示「原文 → 改写后」（含组合引用整体重渲染的结果）；
  - **不自动改写的引用**：断链 / 歧义 / 目标被删而保持原文的引用及原因（源节点随操作被删除的引用不列入）；
  - **断链 / 循环问题变化**：按稳定问题身份对齐当前与预演结果，分列**将新增**与**将消失**的断链、循环问题；
  - 所有结果行均可**点击定位当前正文**（按引用 key / 问题身份在当前文档中实时重定位）；
- **版本与失效**：预演记录生成时的**正文版本号**（仅正文文档变化时递增，批注 / 规范用语规则提交不影响）与**歧义确认记录**（确认变化会使改写计划失真）；正文或确认记录变化后预演**标记失效并禁止应用**，需放弃后按最新状态重新预演；
- **一步应用**：未失效时点「**✓ 应用此预演**」，该操作及全部引用改写作为**一步**提交，可用「↶ 撤销 / ↷ 重做」（或 `Ctrl+Z` / `Ctrl+Y`）整体恢复；应用结果与直接在正文执行同一结构操作完全一致；
- **会话内临时数据**：预演不持久化、不随 JSON 导出，放弃或应用后即清空。

### 14. 引用阅读包（引用阅读）

入口：右侧第 6 个标签「**引用阅读**」（应用访问地址见上文，Docker 一键启动后为 **http://localhost:3000**）。

- **生成**：在下拉框选择一条（或在「关系视图」图中先确认条款编号）后点「**生成阅读包**」。系统以该条为起点，沿**当前已确认后的解析图**向「目标方向」广度优先遍历，逐层收集它直接及间接引用（依赖）的条款：
  - **组合引用的每个已解析目标都参与收集**（如「第三条、第五条及第七条」会分别沿三条继续收集）；闭区间展开为区间内各条；
  - 款 / 项引用归并到其所属条（收集单位为条，展示时仍给出完整款、项）；
  - **循环与多路径汇合只收录一次**（按最短引用距离标注层级：起点、第一层直接依赖、其余为间接依赖），循环上的条款加「↻ 循环」徽标，页脚报告去重的循环 / 汇合路径条数；
  - 条内自指（如以绝对形式回指本条）不构成条款间依赖路径，不会沿它扩展。
- **完整原文按原文档顺序展示**：收录条款不按依赖层级重排，而是按其在文档中的先后顺序展示**完整条款及其全部款、项**，**保留原编号与正文、不改写原文**（编号含「之一 / 之二」后缀；款、项按结构位置编号）。起点条单独高亮；每条款头标注层级徽标。
- **断链 / 歧义引用另列警示**：阅读包末尾单列收录条款中的**断链**与**未确认歧义**引用，逐条标明**来源条款、引用原文与原因**（组合引用部分缺失时列出缺失成员）；已由用户确认的歧义按确认目标参与收集、不再列为警示。该节用于明确提醒摘录**并非自足**，援引前需回原文核对。
- **一键复制纯文本**：点「**📋 复制纯文本**」把整份阅读包（头部说明 + 完整条款原文 + 断链 / 歧义警示节）复制为纯文本，可直接粘贴到其他文稿；不输出 HTML、不改写任何原文。
- **从条目跳回正文**：点击阅读包中任一条的标题即滚动定位到正文该条（折叠时自动展开）；点击任一警示行跳回正文对应的源句并高亮引用。
- **变化后必须重新生成，不能复制旧结果**：阅读包是生成时刻正文（含编号、款、项）与歧义确认记录的**只读冻结快照**。一旦**正文 / 结构变化**（文档版本变化）或**歧义确认变化**，旧阅读包立即标记「已过期」：复制按钮禁用、警示行不可跳转，并提示点「**↻ 重新生成**」按最新状态重建；起点条款被删除时需重新选择起点。
- **会话内只读分析**：阅读包不修改正文、不写入撤销历史、不持久化、不随 JSON 导出；粘贴 / 导入新文档或载入示例时已生成的阅读包清空。同一会话可保留多个阅读包（列表在生成区，最新在前），可逐个查看或删除。

## 数据保存在哪里

- 浏览器 `localStorage`（键 `clause-reference-validator:v1`）：编辑时即时保存；
- 后端本地文件：每次变更后约 0.6 秒防抖写入
  - Docker：`/data/state.json`（持久卷）
  - 本机：`~/.clause-reference-validator/state.json`，可用环境变量 `DATA_DIR` 更改；
- 首次打开若浏览器无数据，会尝试读取后端文件（便于换浏览器共享），否则载入内置示例。
- 后端仅监听本地 HTTP，提供 `/api/state`（GET/PUT）、`/api/health`，不连接任何外部服务。

## 自检
